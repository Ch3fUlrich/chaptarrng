When an audio file has matching audiobook and representative ebook/print candidates, the matcher now prefers the audiobook when their stronger title, narrator, duration, author, and series evidence is tied. This keeps rename previews on audiobook metadata when catalog details are incomplete, while retaining the existing representative-edition fallback when no suitable audiobook candidate is available.
